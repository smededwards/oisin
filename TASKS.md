# Oisin project tasks

Next features are intentionally ordered to preserve Oisin's quiet, vibration-led ADHD time-awareness purpose.

## 1. Focus sessions — next

- [ ] Add temporary 10, 25, 45, and 60-minute focus-session presets.
- [ ] Start, pause, resume, and stop a session from the watch.
- [ ] Keep focus sessions separate from the recurring schedule.
- [ ] Show remaining time in the watch app without creating a notification.
- [ ] Add a distinctive end vibration.
- [ ] Consider optional repeating focus/break cycles, such as 25/5.

## 2. Named modes

- [ ] Add one active mode at a time: Work, Creative, Evening, Sleep, and Custom.
- [ ] Give each mode its own days, time window, interval, and vibration settings.
- [ ] Add phone controls for creating, editing, and selecting modes.
- [ ] Sync the selected mode and its schedule to the watch.
- [ ] Preserve the current single-schedule flow as the default mode.

## 3. Hourly visual awareness

- [ ] Investigate a Wear OS complication for the user's existing watch face.
- [ ] Design an hourly marker or colour change that is visible but unobtrusive.
- [ ] Keep the vibration as the primary cue.
- [ ] Confirm the limits of updating another watch face from the background before implementation.

## Product guardrails

- [ ] Keep Oisin quiet and vibration-led.
- [ ] Avoid notification clutter unless explicitly chosen by the user.
- [ ] Use Conventional Commits and SemVer tags for each release.
