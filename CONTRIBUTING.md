# Contributing to Oisin

## Commits

Use Conventional Commits:

```text
<type>(<scope>): <imperative summary>
```

Examples: `feat(wear): strengthen hourly haptic` and `fix(mobile): refresh next nudge summary`.

## Releases

Oisin uses Semantic Versioning. Release tags must be `vMAJOR.MINOR.PATCH`, for example `v0.1.0`.
